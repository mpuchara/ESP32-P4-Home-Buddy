# Current development user guide

Only use the experimental display profile after checking HARDWARE.md.
The initial screen honestly shows unavailable UBox image/time/temperature.
Tap once to open the diagnostics menu. Adjust the backlight slider; a 10% floor
prevents accidental blackout. Settings are temporary and revert on restart.
The optional Wi-Fi scan button queues work and reports the result through USB
serial logs. No network credentials are saved and no AP connection is performed.
After 30 seconds without touch the screen returns automatically.

Domownicy, Rozpoznawanie, Home Assistant and Kamera UBox are marked "W przygotowaniu".
Enrollment, recognition, HA pairing, calibration, updates and factory reset are not
available yet. Do not use this guide as instructions for those future features.
